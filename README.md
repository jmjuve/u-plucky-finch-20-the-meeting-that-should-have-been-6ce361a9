Entry for the [make.fun bounty "The Meeting That Should Have Been an Email"](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9): a program that writes one funny line about a meeting that should have been an email. The line is the whole entry — no code, no attachments, no second line.

## The line

> We gathered six people in a room to read an email aloud, then scheduled a follow-up to discuss the email we just read.

## Run

```sh
python3 main.py
```

Writes the line to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) and prints the character count. Deterministic — the same output on every run. Python 3.13, standard library only, no network.
